# Docs

JabKit is a source-distributed React component library. This directory is the engineering knowledge base for humans and coding agents. **Repository code is authoritative** when a document disagrees with the implementation.

Start at root [AGENTS.md](../AGENTS.md), then this index, then the task-specific doc, then the files that doc names.

Durable architectural decisions, when they need a record, may be added under `docs/decisions/`. Do not invent historical ADRs.

| [architecture.md](architecture.md) | Monorepo layout, ownership, generated artifacts, boundaries | First time in the repo, or a change that crosses packages |

## Agents, issues, and implementation

- Root `AGENTS.md` is a **router** into this directory, not a second copy of it.
- Nested `AGENTS.md` files under `apps/showcase` and `.shadcn-src` are mostly generated by `next dev`. Showcase-local facts live in a short section outside those markers; see [architecture.md](architecture.md).
- GitHub issues describe intent. The code and these docs describe what exists. Prefer linking to a doc from an issue over restating architecture in the ticket.
- When behavior changes, update the owning document in the same PR. Do not leave `docs/` describing the previous pipeline.
