# DAYMARK

Independent JabKit bento app for epic #545. Start with [the workspace guide](../../docs/standalone-design-systems.md).

Run `pnpm --filter @jabkit/bento dev` from the root (port 3110). Use the same filter with `build`, `start`, or `typecheck`. This app owns `app/globals.css`, `app/theme.css`, `app/style.module.css`, and its public assets.
