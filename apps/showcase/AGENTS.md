# JabKit showcase (local)

This app is catalogue chrome, not the library. Full map: [docs/showcase.md](../../docs/showcase.md).

- `@/*` in this package maps to `packages/ui/src/*`. `@/atoms/button` is the library. Use relative imports for files under `apps/showcase`.
- `public/r/*.json` is generated by `pnpm registry:build` and committed. Do not edit it by hand.
- `lib/preview-manifest.generated.ts` is generated and gitignored. Preview routes 404 when a name is missing from it; they do not fall back to Button.
- `/preview/[name]/[story]` theming is `?theme=` (plus forced dark for `ThemeComparison`). Iframes do not inherit `next-themes` on the parent document. See [docs/theming.md](../../docs/theming.md).
