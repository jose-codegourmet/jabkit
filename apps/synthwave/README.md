# AFTERIMAGE

Independent JabKit synthwave app for epic #542. Start with [the workspace guide](../../docs/standalone-design-systems.md).

Run `pnpm --filter @jabkit/synthwave dev` from the root (port 3108). Use the same filter with `build`, `start`, or `typecheck`. This app owns `app/globals.css`, `app/theme.css`, `app/style.module.css`, and its public assets.
