# AER FORM

Independent JabKit glassmorphism app for epic #543. Start with [the workspace guide](../../docs/standalone-design-systems.md).

Run `pnpm --filter @jabkit/glassmorphism dev` from the root (port 3109). Use the same filter with `build`, `start`, or `typecheck`. This app owns `app/globals.css`, `app/theme.css`, `app/style.module.css`, and its public assets.
