# NIGHTSHIFT

Independent JabKit cybercore app for epic #537. Start with [the workspace guide](../../docs/standalone-design-systems.md).

Run `pnpm --filter @jabkit/cybercore dev` from the root (port 3107). Use the same filter with `build`, `start`, or `typecheck`. This app owns `app/globals.css`, `app/theme.css`, `app/style.module.css`, and its public assets.
