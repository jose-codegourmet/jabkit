# Pillo

Independent JabKit claymorphism app for epic #536. Start with [the workspace guide](../../docs/standalone-design-systems.md).

Run `pnpm --filter @jabkit/claymorphism dev` from the root (port 3106). Use the same filter with `build`, `start`, or `typecheck`. This app owns `app/globals.css`, `app/theme.css`, `app/style.module.css`, and its public assets.
