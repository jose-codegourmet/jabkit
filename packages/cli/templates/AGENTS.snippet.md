## UI components (JabKit)

This project uses JabKit. Read `.github/skills/jabkit-component/SKILL.md` and MCP `get_conventions` before selecting components. Answer JabKit's two discovery questions about intent (audience, desired action, required functionality) and visual direction (tone, references, assets, things to avoid). Use existing context; ask the user only for material missing details. Include both answers as `brief.intent` and `brief.visualDirection` on every catalogue call, reusing them across the task. A `needs_brief` response requires answering its questions and retrying, not selecting components. For branded pages, compare candidates using `tone`, `bestFor`, `avoidFor`, `visualWeight`, layout, and capabilities. Search beyond the first results; explain fit and adaptations. Install pristine source into the configured components directory, then adapt local composition, typography, spacing, imagery, and motion to the brief. Semantic classes consume brand-specific `--jk-*` values; default palettes and sample presets are optional. Replace all demo branding and unsupported proof claims, then review desktop/mobile and supported themes.
