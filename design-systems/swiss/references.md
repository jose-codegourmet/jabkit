# Swiss Design: reference review

## Source status

The implementation brief originated in a style sample list from talhaxcodes and was split into [FRAME/01 epic #546](https://github.com/jose-codegourmet/jabkit/issues/546). No individual reference-site URLs were assigned to this specification in `TO_EXTRACT.md`.

Review date: 2026-09-30.

## Evidence available

The epic provides the product problem, brand, palette, typography direction, grid rules, program records, page inventory, component candidates, image prompts, accessibility requirements, and ordered implementation tickets. Those requirements are treated as authored project direction rather than observations copied from an external website.

## Interpretation for JabKit

FRAME/01 translates Swiss Design into a working film-festival information system:

- an explicit 12/8/4-column grid;
- Inter Tight with strong numerals and compact facts;
- paper, near-black, cool gray, and one signal-red marker;
- stable film stills within aligned column spans;
- schedule and ticket state represented in semantic text and controls;
- square geometry, ruled group boundaries, and restrained motion.

This direction is not a claim that Swiss Design has one official web component library, palette, or motion system. It is an original JabKit application of grid-based international typographic principles to the supplied festival brief.

## Limitations

No external reference was inspected for exact CSS, font licensing, animation timing, or responsive behavior. The proposed values in this folder are authored recommendations. Inter Tight must be self-hosted with its license during implementation. Final accessibility and visual quality depend on the rendered app, approved imagery, real content length, browser behavior, and both color modes.
