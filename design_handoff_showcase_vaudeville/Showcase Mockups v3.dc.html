get_install_plan

read-only

Walks registryDependencies depth-first, in the same order as the CLI. This is a plan, not an install.

Arguments

NameTypeNotes
namesstring[]Required
targetDirstringDefault src/components/jabkit

Request

curlfetchprompt⧉ Copy
curl -X POST /mcp \
  -H "Content-Type: application/json" \
  -d '{
    "tool": "get_install_plan",
    "arguments": { "names": ["button"] }
  }'

Response 200

{
  "filesToCreate": [ ".../atoms/button/Button.tsx", … ],
  "filesToOverwrite": [],   // always empty
  "npmDeps": [ "class-variance-authority" ],
  "cssVars": { "light": {}, "dark": {} }
}

Errors

400{ "error": "Unknown component: …" }
